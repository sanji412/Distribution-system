# 企业级智能分销与订单履约平台前端高仿版设计

## 1. 背景与目标

当前后端已完成五个业务服务的基础拆分，并具备订单履约看板所需的演示接口和初始化数据。Nacos、OpenFeign、Gateway 尚未接入，因此前端第一版不阻塞等待服务治理能力，而是先完成与老师运行效果高度接近的深色管理后台界面。

前端第一版目标：

- 建立独立 Vue3 前端模块，后续作为最终系统前端持续演进。
- 高度贴近老师示例页面的整体视觉、导航结构、暗色卡片、表格和状态标签。
- 优先完成订单履约页真实数据联调，确保今日订单、今日成交额、待发货、异常订单和订单列表可展示。
- 服务治理、数据看板、AI 客服、系统监控先使用 mock 数据完成页面效果，后续按课程进度替换为 Nacos、Gateway、Sentinel、DeepSeek 等真实接口。
- 请求层预留统一入口，后续 Gateway 完成后只改 API 基础路径，不重写页面。

## 2. 技术选型

| 类型 | 选型 | 说明 |
| --- | --- | --- |
| 构建工具 | Vite | 快速启动 Vue3 前端项目 |
| 前端框架 | Vue3 Composition API | 与实训方案一致，便于组件拆分 |
| UI 组件 | Element Plus | 提供表格、按钮、标签、输入框等后台常用组件 |
| HTTP 请求 | Axios | 封装服务请求，方便后续切换 Gateway |
| 图表 | ECharts 或轻量 CSS 图表 | 数据看板第一版可以先用 CSS 柱状图，后续再接 ECharts |
| 样式 | 原生 CSS / CSS Modules | 第一版重点还原深色视觉，避免过度引入样式框架 |

## 4. 页面布局

整体采用老师示例的深色后台布局：

- 顶部导航栏固定在页面上方，高度约 64px。
- 左侧为窄图标侧栏，宽度约 68px。
- 主内容区铺满剩余空间，深色背景。
- 页面不做营销首页，打开后直接进入可操作的监控后台。

顶部导航栏包含：

- 左侧平台标题：智能分销平台监控。
- 中间菜单：服务治理、订单履约、数据看板、AI 客服、系统监控。
- 右侧用户标识：`ADMIN`、`admin`。

左侧图标栏包含：

- 服务治理图标。
- 订单履约图标。
- 数据看板图标。
- AI 客服图标。
- 系统监控图标。

主内容区根据当前菜单切换页面。第一版不引入复杂路由，也可以通过组件状态切换实现；后续页面增多后再接 Vue Router。

## 6. 数据流设计

第一版数据流：

```text
Vue 页面
  -> api/order.js
  -> Axios
  -> order-service:8082
  -> R<T> 统一响应
  -> 页面渲染
```

mock 页面数据流：

```text
Vue 页面
  -> api/mock.js
  -> 本地静态数据
  -> 页面渲染
```

后续 Gateway 接入后的数据流：

```text
Vue 页面
  -> api/*.js
  -> Axios
  -> gateway-service
  -> 各业务服务
  -> R<T> 统一响应
  -> 页面渲染
```

API 封装原则：

- 页面不直接写 `axios.get`。
- 所有请求放入 `src/api`。
- `http.js` 统一处理 `baseURL`、响应解包和错误信息。
- 当前订单履约接口可直连 `http://localhost:8082`。
- 后续只需把 `baseURL` 改成 Gateway 地址。

## 7. 视觉设计

视觉目标是贴近老师运行截图，而不是重新设计一套全新风格。

色彩规则：

- 页面背景：近黑色。
- 顶栏和面板：深灰黑。
- 边框：低亮度灰色。
- 主要强调色：蓝色。
- 成功状态：绿色。
- 警告状态：黄色。
- 异常状态：红色。

组件规则：

- 页面区域用全宽布局，不做过多漂浮大卡片。
- 指标卡片使用左侧彩色竖线区分类型。
- 表格保持紧凑，适合后台扫描。
- 状态用小型标签展示，例如 `已支付`、`待支付`、`库存不足`、`已完成`。
- 订单列表中的 `stock:8003`、`pay:8006` 使用蓝色服务标签，失败状态使用红色标签。

响应式要求：

- 桌面端优先，适配常见 1440px、1920px 宽度。
- 低于 900px 时，指标卡片允许换行，表格允许横向滚动。
- 文字不能遮挡或溢出按钮、标签、表格单元格。

## 8. 错误与加载状态

订单履约页需要处理以下状态：

- 加载中：显示简洁 loading 状态。
- 接口成功：渲染真实数据。
- 接口失败：展示错误提示，并回退到 mock 演示数据，保证课堂展示不中断。
- 数据为空：表格展示空状态。

错误提示不做复杂弹窗，第一版可以在页面顶部或面板内显示一条轻量提示。

## 9. 测试与验收标准

开发完成后需要验证：

- 前端项目可通过 `npm install` 和 `npm run dev` 启动。
- 顶部五个导航可切换页面。
- 页面整体为深色风格，布局接近老师运行效果截图。
- 订单履约页可请求 `order-service:8082/api/order/dashboard`。
- 当订单服务启动时，页面展示：
  - 今日订单 `1280`
  - 今日成交额 `¥128K`
  - 待发货 `23`
  - 异常订单 `5`
  - 5 条订单列表
- 当订单服务未启动时，页面仍能展示 mock 数据，并给出轻量提示。
- 桌面宽度下无明显文字重叠、表格错位、按钮溢出。

## 10. 非目标范围

第一版不实现以下内容：

- 登录鉴权。
- Vue Router 完整路由体系。
- Nacos 真实服务注册页面。
- OpenFeign 真实跨服务调用。
- Gateway 统一入口。
- Sentinel 真实限流规则管理。
- DeepSeek 真实对话调用。
- Seata 分布式事务链路动画。

这些能力将在后续课程完成对应后端能力后逐步接入。
