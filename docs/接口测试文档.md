# 企业级智能分销与订单履约平台接口测试文档

## 一、测试说明

| 项目 | 内容 |
| --- | --- |
| 测试日期 | 2026-06-26 |
| 测试阶段 | 微服务拆分、Nacos 注册发现、OpenFeign 跨服务调用与订单履约页面数据联调 |
| 测试目标 | 验证用户、商品、库存、订单、支付五个服务的基础查询接口可用，验证五个服务可注册到 Nacos，验证订单中心可通过 OpenFeign 调用商品、库存、支付服务，验证订单履约页四个统计指标和订单列表可正常返回 |
| 数据来源 | `distribution-platform/sql/final-system-init.sql` |
| 数据库 | MySQL 8，端口 `3307`，五库拆分：`user_db`、`product_db`、`stock_db`、`order_db`、`pay_db` |
| 统一返回格式 | `{ "code": 200, "msg": "操作成功", "data": ... }` |

> 当前阶段已接入 Nacos 注册发现与 OpenFeign 跨服务调用；订单列表中的库存服务、支付服务字段仍保留页面演示标签，跨服务调用通过订单远程详情接口单独验证。

## 四、重点接口测试详情

### 1. 订单履约看板接口

| 项目 | 内容 |
| --- | --- |
| 请求方式 | GET |
| 请求地址 | `http://localhost:8005/api/order/dashboard` |
| 测试目的 | 一次性获取订单履约页面顶部 4 个指标和下方订单列表 |

预期响应核心字段：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "summary": {
      "todayOrderCount": 1280,
      "todayTradeAmount": 128000.00,
      "pendingDeliveryCount": 23,
      "exceptionOrderCount": 5
    },
    "orders": [
      {
        "orderNo": "DD202505190001",
        "productName": "机械键盘-Keychron K3",
        "productNum": 2,
        "totalAmount": 736.00,
        "orderStatus": "已支付",
        "stockService": "stock:8003",
        "payService": "pay:8006",
        "orderTime": "09:30"
      }
    ]
  }
}
```

测试结论：订单履约看板接口返回成功，四个统计指标与页面设计一致，订单列表可正常展示。

### 2. 订单跨服务详情接口（OpenFeign）

| 项目 | 内容 |
| --- | --- |
| 请求方式 | GET |
| 请求地址 | `http://localhost:8005/api/order/remote-detail/DD202505190001` |
| 测试目的 | 验证订单中心可通过 OpenFeign 按 Nacos 服务名调用商品中心、库存中心和支付中心 |

预期响应核心字段：

```json
  "msg": "操作成功",
  "data": {
    "orderNo": "DD202505190001",
    "productService": "product-center",
    "stockService": "stock-center",
    "payService": "pay-center",
    "product": {
      "productId": 1,
      "productName": "机械键盘-Keychron K3"
    },
    "stocks": [
      {
        "productId": 1,
        "warehouseId": 1,
        "stockNum": 50
      }
    ],
    "payment": {
      "orderNo": "DD202505190001",
      "payStatus": "支付成功"
    }
  }
}
```

测试结论：订单中心通过 `product-center`、`stock-center`、`pay-center` 服务名完成跨服务调用，说明 Nacos 服务发现与 OpenFeign 负载均衡链路可用。

### 4. Nacos 配置中心演示接口

| 项目 | 内容 |
| --- | --- |
| 请求方式 | GET |
| 请求地址 | `http://localhost:8002/api/product/config` |
| 测试目的 | 验证商品服务可以读取本地默认配置，并可被 Nacos 中的 `product-center-dev.properties` 动态覆盖 |

Nacos 控制台可创建配置：

```properties
product.config.stock=100
product.config.desc=Nacos远程配置-商品库存
```

预期结果：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "serviceName": "product-center",
    "serverPort": "8002",
    "stock": 100,
    "desc": "Nacos远程配置-商品库存"
  }
}
```

测试结论：未创建远程配置时返回本地默认值；Nacos 发布配置后，可用于验证配置中心读取和动态刷新效果。

## 五、测试结论

本次接口测试覆盖了用户中心、商品中心、库存中心、订单中心、支付中心五个微服务模块。基础查询接口均符合统一响应格式，订单履约页面所需的今日订单、今日成交额、待发货、异常订单和订单列表数据能够正常返回。当前阶段系统已完成微服务基础拆分、Nacos 注册发现、Nacos 配置中心演示和 OpenFeign 跨服务调用，可作为后续 Gateway 网关、Seata 分布式事务和 Sentinel 限流熔断功能的开发基础。
