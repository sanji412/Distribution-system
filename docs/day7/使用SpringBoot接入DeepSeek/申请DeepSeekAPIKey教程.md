## 申请DeepSeekAPIKey详细教程

#### **1. 访问官网并登录**

打开 DeepSeek 开放平台：**[https://platform.deepseek.com](https://platform.deepseek.com/)**
点击右上角“登录 / 注册”，用手机号或邮箱注册一个账号（已有账号直接登录）。

#### **2. 进入 API Keys 管理页**

登录后，在左侧菜单找到 **“API Keys”**（或“接口密钥”），点击进入。

#### **3. 创建新的 API Key**

点击 **“创建 API Key”** 按钮，给密钥起个便于记忆的名字（如 `my-app`），然后确定。系统会生成一串密钥字符串。

#### **4. 复制并妥善保存**

生成后**立即复制**保存到安全的地方（如密码管理器）。这个密钥只显示一次，关闭弹窗后将无法再次查看完整密钥。

#### 5.账户储值

deepseek是收费接口，的账户非储值状态不可用，需要储值之后才能使用。

打开https://www.deepseek.com/，点击“API开放平台”，默认处于“用量信息”标签，点击“去充值”进行储值。首次使用需要进行实名认证，认证时使用个人即可。
